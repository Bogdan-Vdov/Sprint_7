# Sprint 7 - Тестирование API Яндекс.Самокат

Проект содержит автотесты для API сервиса Яндекс.Самокат (https://qa-scooter.praktikum-services.ru/)

## Структура проекта

- `helpers.py` - вспомогательные функции для работы с API
- `test_create_courier.py` - тесты для создания курьера
- `test_login_courier.py` - тесты для авторизации курьера
- `test_create_order.py` - тесты для создания заказа (с параметризацией)
- `test_get_orders.py` - тесты для получения списка заказов
- `requirements.txt` - зависимости проекта
- `pytest.ini` - конфигурация pytest

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск тестов

Запуск всех тестов:
```bash
pytest
```

Запуск с подробным выводом:
```bash
pytest -v
```

Запуск конкретного файла:
```bash
pytest test_create_courier.py -v
```

## Генерация Allure-отчёта

Запуск тестов с генерацией отчёта:
```bash
pytest --alluredir=allure-results
```

Просмотр отчёта:
```bash
allure serve allure-results
```

## Описание тестов

### Создание курьера (test_create_courier.py)
- ✅ Курьера можно создать
- ✅ Нельзя создать двух одинаковых курьеров
- ✅ Проверка обязательных полей (login, password, firstName)
- ✅ Проверка кода ответа и тела ответа

### Логин курьера (test_login_courier.py)
- ✅ Курьер может авторизоваться
- ✅ Проверка обязательных полей (login, password)
- ✅ Ошибка при неправильном логине или пароле
- ✅ Ошибка при авторизации несуществующего пользователя
- ✅ Успешный запрос возвращает id

### Создание заказа (test_create_order.py)
- ✅ Можно указать цвет BLACK
- ✅ Можно указать цвет GREY
- ✅ Можно указать оба цвета
- ✅ Можно не указывать цвет
- ✅ Тело ответа содержит track

### Получение списка заказов (test_get_orders.py)
- ✅ В тело ответа возвращается список заказов
